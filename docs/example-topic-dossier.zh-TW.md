## 2. 候選主題定義

**候選主題 1 — LLM 驅動的水資源管理。** 使用 LLM 與 LLM 代理人進行水資源管理和決策支援：水文預測、水庫與河流操作、監測及規劃。*受檢驗的初始缺口假設：* 將 LLM 廣泛應用於水資源管理可能尚未被嘗試。檢索所得的先期研究已反駁此廣泛假設。

**候選主題 2 — 用於社會水文學中人類行為的 LLM 代理人。** 在一個人與水耦合（社會水文學）模型中，使用 LLM 代理人來代表個別利害關係人和家戶如何做出用水決策，並根據觀察到的用水和調適行為對這些代理人進行校準與檢驗。*仍待檢驗的缺口假設：* 在社會水文學模型中，以校準過的 LLM 代理人表徵利害關係人行為，可能研究不足。選入文獻中未辨識出相符實作；是否不存在於更廣泛的文獻中，仍未驗證。

## 5. 逐關卡評估

### 關卡 1 — 缺口仍開放

- **分數。** 候選主題 1：1/5 (強烈不同意)。候選主題 2：3/5 (中立)。
- **證據。** 對於候選主題 1，此領域已有一個基準、一篇系統性綜述、一篇文獻計量分析，以及原創的微調和對話式代理人研究 — 這些檢索所得研究反駁了整個領域尚未被嘗試的主張。對於候選主題 2，選入文獻中未辨識出完成校準過 LLM 代理人於社會水文學之任務的論文；只有一篇領域內的相近類比 (Batista 2025, 情感分析) 和一篇警示論文 (Schück 2026) 與此議題相關。
- **詮釋。** 候選主題 1 的廣泛新穎性主張缺乏支持；較窄任務能否提供貢獻，需另行評估。候選主題 2 在該次中等信心的歷史檢索後，仍是缺口假設，而非已確認開放的缺口。
- **風險。** 執行期間 Semantic Scholar 受到速率限制，因此可能遺漏了與候選主題 2 相關的論文。「缺席於此文獻庫」不等於「開放」的證明。
- **所需行動。** 在提出候選主題 2 目前開放性的主張之前，需啟用 Semantic Scholar API 金鑰重新執行檢索並評估涵蓋度；新增後端不保證完整召回。

### 關卡 2 — 實質貢獻

- **分數。** 候選主題 1：未評估 (未通過關卡 1)。候選主題 2：3/5 (中立)。
- **證據。** 有限文獻庫中未辨識出已放棄的嘗試。Schück (2026) 是一篇經同儕審查的觀點論文，其前提正是一個持續存在的警示。Batista (2025) 是領域內最接近的先期研究，使用 LLM 於水資源治理的人類信號，但其為情感分析，而非基於代理人的決策模型。
- **詮釋。** 候選主題 2 預期貢獻的是**一種用 LLM 代理人來代表家戶用水調適決策的已驗證方法** — 這些代理人的選擇經校準，並與觀察到的調適行為進行比對測試，可作為社會水文學模型的行為層。這是預期的貢獻，尚非已完成的驗證結果。其價值取決於行為表徵，而非「LLM 代理人應用於水資源」這個廣泛標籤。創新性屬界線模糊；驗證要求是能將此研究從延伸性工作提升為新能力的關鍵。
- **風險。** **構念效度** — LLM 生成的行為是否忠實地代表真實的人類用水決策，或僅是看似合理。這正是 Schück 提出的風險。
- **所需行動。** 提案必須滿足的最低驗證草圖：行為目標 = 觀察到的家戶調適決策（例如，家戶是否採取防洪措施或在缺水時改變用水行為）；基線 = 傳統的離散選擇模型或規則式 ABM 代理人；留出測試 = 在 LLM 代理人未經調校的留出家戶集合上預測決策；研究必須克服的主要失敗模式 = 看似合理但與母體不符的行為。

### 關卡 3 — 可行性

- **分數。** 候選主題 1：未評估 (未通過關卡 1)。候選主題 2：3/5 (中立)。
- **歷史可行性假設。** 原紀錄將家戶用水與調適行為資料描述為部分公開、水文資料為大多公開，並將 LLM API 描述為可按用量付費取得。本備忘錄未驗證資料適用性、存取權或目前費用。基線模型 (離散選擇模型 / 規則式 ABM) 是標準的。家戶行為資料涉及隱私與同意限制 — 目標性調查需倫理審查批准。再現性是一項隱憂：LLM 輸出依賴外部 API 模型。一篇碩士論文規模的專案，適合一個區域、數百家戶的行為資料、一個社會水文學耦合，大約需 12–18 個月的工作；原始 LLM API 成本估計為數百美元。這些範圍、時程與費用均為歷史規劃假設，不代表已證實的可行性或目前報價。
- **詮釋。** **主要限制**是行為驗證資料集。歷史評估支持在取得適用資料並完成驗證的條件下發展提案。論文可行性仍未驗證：資料再利用、初級資料蒐集、倫理要求、資源及時程均需明確檢核。若需初級資料蒐集，依原規劃估計，可能佔據第一年的主要時間。
- **風險。** 家戶行為資料的隱私與同意限制，加上再現性 — LLM 代理人輸出依賴可能改變或淘汰的外部 API 模型。
- **所需行動。** 找出一可重複使用的觀察行為資料集 (一個值得先查核的線索：Jiang et al. 2026 為華北平原建立了包含政策情境的社會水文學模型)。若無，則規劃一個符合專案時程並包含倫理審查批准的初級資料蒐集計畫。鎖定 LLM 模型版本並存檔提示與輸出以確保再現性。

## 6. 風險與升級／否決測試

**已識別風險。**

- **構念效度風險** — LLM 生成的行為是否忠實地代表真實的人類用水決策，或僅是看似合理；這正是 Schück (2026) 針對候選主題 2 所採方法提出的風險。
- **資料集限制風險** — 行為驗證資料集是候選主題 2 可行性的主要限制；若找不到可重複使用的資料集，初級資料蒐集將佔據主要時程。
- **創新性風險** — 候選主題 2 介於新能力與延伸性工作之間的界線；Batista 2025 是一個較弱的已實現形式 (用於水資源治理的 LLM 情感分析)，專案必須超越之。
- **再現性風險** — LLM 輸出依賴外部 API 模型；設計必須鎖定模型版本並存檔提示與輸出，以便在 API 模型改變或淘汰時能重新執行研究。

**升級／否決測試 — 候選主題 2：用於社會水文學中人類行為的 LLM 代理人。** 歷史條件式建議取決於以下**所有**檢核項目。此處未記錄檢核已完成；即使條件成立，仍需研究者明確做出選題決定。

1. 啟用 Semantic Scholar，擴大檢索並記錄涵蓋度及更新後的篩選，確認是否已有研究在社會水文學中建立校準過的 LLM 代理人。未找到相符研究僅支持有限範圍內的未發現主張，不能證明缺口開放。
2. 一項先導研究產出留出測試驗證結果，其中 LLM 代理人預測觀察到的家戶調適決策的表現，至少與在相同留出集合上的離散選擇或規則式 ABM 基線相當。
3. 已找到一可重複使用的觀察行為資料集，或已備妥一份符合專案時程並包含倫理審查批准的初級資料蒐集計畫。

歷史否決條件包括貢獻已被相符研究實現、校準或簡單基線比較失敗，以及範圍內無法取得行為資料集。若出現這類證據，研究者應停止或縮小候選主題。僅找到相關論文不足以排除不同的貢獻，仍須比較實際任務與證據。

**補救路徑 — 候選主題 1：LLM 驅動的水資源管理。**
文獻庫反駁了整個領域尚未被嘗試的廣泛主張，但某個特定的研究不足子問題仍可能存在 — 例如，現有基準和綜述文獻未涵蓋的特定水資源管理任務。要挽救此主題，需要針對該子問題而非廣泛領域進行全新的、更窄的檢索。

## 7. 建議的下一步

歷史篩選建議是不以原述形式推進廣泛的「LLM 驅動的水資源管理」主題。檢索所得的基準、系統性綜述與文獻計量分析削弱了整個應用領域尚未被嘗試的主張，但不能據此認定所有較窄的貢獻都不存在。若對現有文獻服務不足的特定水資源管理子問題感興趣，下一步應是針對該子問題進行全新的、更窄的檢索。

較窄的「用於社會水文學中人類行為的 LLM 代理人」在歷史篩選中被保留為條件式假設，目前狀態未知。在投入之前，需採取三項行動：啟用 Semantic Scholar 重新檢索，記錄涵蓋度並重新評估缺口；閱讀 Schück (2026) 並圍繞其構念效度警示設計驗證 — 至少包含對真實家戶調適決策，與離散選擇或規則式 ABM 基線進行留出測試比較；以及，找到一可重複使用的行為資料集，或規劃一個符合專案時程並包含倫理審查批准的初級資料蒐集計畫。隨後研究者必須明確記錄選擇、修改、暫緩或否決該主題的決定及理由。本備忘錄未記錄目前的人為選題決定。
